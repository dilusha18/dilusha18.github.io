# Dilusha Heshan Hemachandra - Engineering Portfolio

Personal portfolio for Dilusha Heshan Hemachandra, a Mechanical Engineering undergraduate at the University of Moratuwa focused on product development, mechanical design, robotics, mechatronics, industrial automation, and R&D.

## Portfolio content

- Mechanical design and CAD capabilities
- Product development, robotics, embedded systems, and IoT work
- Six selected engineering projects, two ongoing projects, and an extra engine design study, each with a linked detail view and image gallery
- Education, A/L results, technical skills, and competition achievements with expandable certificate photographs
- Downloadable CV and direct contact links
- Team GitHub links, a Pattiya LinkedIn article, and a looping UAV mechanism video

## Built with

- Semantic HTML5
- Responsive CSS
- Vanilla JavaScript
- Locally bundled Ionicons (license in `assets/icons-LICENSE`)
- Self-hosted Barlow Condensed and Public Sans fonts (licenses in `assets/fonts`)

The visual design uses a graphite identity header, a light work area, condensed display typography, and restrained lime accents. Motion respects reduced-motion preferences; the UAV video retains its user-requested autoplay and loop controls.

## Live site

The site is intended for GitHub Pages at [dilusha18.github.io](https://dilusha18.github.io/).

Project details support direct links, such as `#projects/extruder`. Project descriptions and gallery entries are maintained in `assets/js/projects.js`.

CSS and JavaScript links in `index.html` use content-hash query versions. After editing an asset, refresh its `?v=` value with the first eight characters of its SHA-256 hash so mobile browsers request the latest version.

## Local preview

Open `index.html` directly or serve the directory with any static web server.
